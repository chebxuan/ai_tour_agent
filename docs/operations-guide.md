# 当前运营使用说明

适用对象：现有 Streamlit Demo 的销售/计调用户。页面实现位于 `legacy/streamlit_app.py`。这是现行操作说明，旧 v1 手册保存在 `archive/operations-manual-v1.md`。

## 标准询单与方案

1. 在标准行程页粘贴客户原文，使用 AI 解析；未配置外部模型时直接手填需求。
2. 人工确认城市、天数、人数、日期、导游、包车和可选项目，不把模型猜测当客户承诺。
3. 生成匹配产品、成本明细和 Markdown 行程；检查未报价项目与风险提示。
4. 修改行程与交付草稿，复核后复制/保存用于后续沟通。

当前产品与成本由库内数据和规则计算。成本总额不等于已统一实现利润规则的最终销售价，发送给客户前需按实际销售要求复核。

## 上海半定制

输入时长、兴趣、节奏、预算与人群，生成路线后检查交通边、雨天适配、老人/亲子条件和未满足的模板要求。路线使用静态数据与部分成本映射，不代表实时预订或实时天气。

详见 [半定制说明](custom_route_mvp.md) 与 [人工复核表](custom_route_human_review.md)。

## 供应商付款记录

当前看板将记录置于待处理、已支付、已归档状态，数据保存在 `data/payments.json`。它是付款管理记录功能，不是在线支付。

旧材料保存在 `references/private/payment-history/`，不会自动导入。现行 JSON 存储尚未具备多人并发所需的事务保护；数据库迁移列在后续路线图中。

## 出现错误时

- 无法访问后端：确认后端已启动，`API_BASE` 指向正确地址。
- 鉴权失败：后端和旧界面需使用相同的服务端 `API_KEY`。
- AI 不可用：检查外部模型配置；手动需求表单仍可使用。
- 产品、费用或可选项缺失：先核对源数据与成本库，不用文案掩盖缺项。

启动方法见根目录 [readme.md](../readme.md)。
