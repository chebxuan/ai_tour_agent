# 旅行网站后端接口

更新：2026-10-09。后端保留独立测试，前端已接入行程预览接口。v3 接口与旧 v2 接口并存，沿用确定性成本算法；本轮校正共享产品编号，并为游轮显式指定陆地导游天数，不调用外部 LLM；普通预览/报价不写咨询，新增咨询提交接口才保存联系信息和快照，付款与旧工作流日志不变。

## 运行与认证

从仓库根目录执行：

```bash
.venv/bin/python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload
```

`API_KEY` 从环境变量或已有 `.env` 读取；不要覆盖现有配置。接口文档在 `http://127.0.0.1:8000/docs`，所有 v3 接口必须提供 `X-API-Key`。错误密钥返回 401；缺少请求头按现有认证契约返回 422。

本次独立 HTTP 检查的进程仅监听本机，使用临时测试密钥 `local-backend-validation-only`，没有修改 `.env`。该值只用于本地检查；正式运行使用自己的服务端配置。浏览器现通过服务端适配层调用，不把共享密钥放进前端。

## 产品目录

`GET /api/v3/products`，可使用 `?city=上海` 筛选。响应包含公开产品与按城市整理的 `available_days`。未知城市返回空目录。

21 个产品的白名单字段：产品编号、名称、城市、天数、每日活动、替代路线、路线概览、可选体验与提示。没有成本单价、供应商、付款或成本原始元数据。可选体验的 `code` 按当前产品允许的编号和成本项目名称交叉核对，不能把名称列表与编号列表按位置配对。不能唯一对应时 `code=null`、`cost_available=false`，费用计算需复核。

上海 SH-P-02/03 的“本帮菜”对应 `SH-ACTIVITY-03`，“法租界小酌”对应 `SH-ACTIVITY-06`；额外存在于编号数组而不在可选名称列表的项目不会自动加入旅客选项。

## 行程预览

`POST /api/v3/trips/preview`

```json
{
  "city": "上海",
  "days": 3,
  "adults": 2,
  "children": 0,
  "seniors": 0,
  "travel_date": "2026-11-08",
  "need_guide": false,
  "need_private_car": false,
  "selected_optional_items": ["本帮菜", "法租界小酌"],
  "notes": "希望多留一些自由活动时间"
}
```

按城市与真实产品天数精确选择；可以附加 `product_id` 固定产品，但必须与城市和天数一致。可选体验可以传名称 `selected_optional_items` 或传编号 `selected_optional_item_codes`，两种方式不能同时使用。禁止重复选择、跨产品项目和未知项目。没有产品时返回 404 与 `available_days`，不会自动返回邻近天数或其他城市。

响应包含 `product`、请求快照 `request`、已选体验 `selected_optional_choices`，以及英文体验介绍 `selected_experiences`。`product.menu` 包含英文产品标题、整线介绍、按实际天数排列的 `days`（主题标题、完整介绍、景点亮点和分支），以及待确认产品的 `overview`。内容来自 `attraction_highlights.json` 与经过校对的 `menu_presentation.json`，不输出原 PDF 价格。20 个产品有逐日路线；重庆 5 日仅展示概览。重庆 2 日、张家界 3 日和阳朔 3 日的分支分开展示，不代表同时安排。保留“外景”“可选”“推荐”限定，不编造游览时间。

人数、日期、导游/包车意愿与备注保留在请求中；备注不进行 AI 解析，日期不用于自动推断旺季。人数总计至多 20 人，成人至少 1 人，日期须有效，备注至多 2000 字符；整数与布尔字段不接受字符串替代，未知字段返回 422。

旅客响应中 `sales_quote.status=pending_confirmation`，`amount=null`，不含内部成本。

## 内部成本估算

`POST /api/v3/internal/cost-estimate`。仅用于服务端/运营验证，不能把此响应整体转发给旅客。

```json
{
  "city": "上海",
  "days": 3,
  "adults": 2,
  "is_peak": true,
  "selected_optional_items": ["黄浦江夜游"],
  "need_guide": true,
  "guide_code": "SH-GUIDE-01",
  "need_private_car": true
}
```

`is_peak` 必填；需要导游时须明确有效的本城市 `guide_code`。复用现有成本引擎，范围仅为常规项目、已选体验、明确要求的导游和包车，不自动加入酒店或机场接送。超过 7 人的包车请求需复核车型与数量，不套用默认单车规则。

响应 `kind=internal_cost_estimate`，`cost` 含成本分项、分类小计与总计；`included_scope`/`excluded_scope` 标明范围。此内部接口的销售报价字段仍为空；对客销售价通过下述独立报价接口计算，不自动改变运营成本。共享 API Key 尚未具备角色划分，后续对外发布前必须进一步隔离运营接口权限。

## 旅客销售报价

`POST /api/v3/trips/quote`，使用与内部成本相同的严格请求字段。`is_peak` 必填；需要导游须选择城市内的 `guide_code`，不根据日期自动推断季节。客户端不能传入成本、售价或倍率。

```json
{
  "city": "重庆",
  "days": 2,
  "adults": 2,
  "is_peak": false,
  "route_choices": [{"day": 2, "choice": "wulong"}],
  "need_guide": false,
  "need_private_car": false
}
```

销售规则由用户指定：**销售价＝核实范围内的成本总额 × 1.3**，即在成本上加价 30%。人民币团体总价，使用 Decimal，最终金额四舍五入到分（ROUND_HALF_UP）。已选体验、明确要求的导游和车辆一并计入基数；不另自动叠加历史表的 10% 供应商操作费，不新增折扣、税费或其他销售规则。这里是所列服务的估算价，不能当作全包旅游总价或已确认订单。

响应白名单：

- `kind=traveller_sales_quote`、`product_id`。
- `sales_quote.status`：`estimated` 或 `pending_confirmation`。
- `amount`、`currency=CNY`、`basis=group_total`、`travellers`。
- `included`、`excluded`、`selected_routes`：英文服务范围。
- `reason`、`notice`：确认状态与英文说明。

以上示例不选服务时，武隆分支双人成本为 600 元，对外估算价为 780 元。对客响应不含成本总额、成本分项、供应商、单价、利润或倍率。内部成本接口仍独立返回成本，不向旅客转发。

分支未选、数据冲突、车型需复核等情况，报价返回 HTTP 200、`pending_confirmation`、`amount=null`；不输出部分金额。错误分支、跨分支可选项、错误导游、未知字段等返回 422。广州 1 日不选收费服务时提示 `NO_PRICED_SERVICES`，不展示整趟旅行免费。

行程预览仍返回待确认报价；2026-10-09 后续联调已完成：前端读取公开目录并选择分支、导游与季节，然后通过 Next.js 服务端调用旅客报价接口；浏览器不请求内部成本接口。报价失败保留 Menu；表单变化后隐藏旧金额。

## 数据库接入（2026-10-09）

本地 PostgreSQL 已导入并启用标准产品、成本、Menu、分支和销售规则。v3 接口契约保持不变，单次请求使用一致的只读事务快照；数据库连接或数据加载失败返回 `503`、`detail.code=DATABASE_UNAVAILABLE`，不会回退旧文件金额。API 预览/报价仍只读，保存报价由运营维护命令显式执行。维护与恢复方法见 [数据库使用说明](database-guide.md)。

本轮联调的新版后端独立运行在 `127.0.0.1:8001`；前端的服务端地址通过环境变量配置。原 8000 验证进程没有被覆盖。


公开目录增加 `quote_guide_options`（仅 code、英文 label）与 `quote_route_options[].excluded_optional_items`（仅本产品项目名）；没有服务单价。Menu 分支的 `choice` 与报价选择键一致，前端据此只展示选中分支，不按标题或数组位置猜测映射。

公开导游选择只提供全程按天的英文导游服务。按次的兵马俑讲解、市场买手不能当作全程导游；这类请求保持 `GUIDE_SCOPE_REQUIRES_REVIEW`，待建立单日/单次服务选择后再开放，避免按行程天数重复收费。

## 旅客咨询提交（2026-10-09 已接入）

`POST /api/v3/trips/enquiries`，浏览器经 Next.js `/api/trips/enquiries` 转发。仍使用服务端认证密钥，浏览器不包含共享密钥。Next.js 校验同源 Origin、JSON 类型和 128 KiB 请求上限；隐藏的空字段 `website` 用作基础垃圾表单过滤，生产防刷仍需在部署阶段配置。

预览新增 `preview_token`，报价新增 `quote_token`，是服务器签名的公开快照，有效 2 小时。前端随咨询原样提交；内容只有旅客本已可见的产品、需求及销售报价，没有内部成本。签名用于校验快照，没有加密公开内容，不应将它当作私人会话或账户令牌。

请求字段：`request_id`（UUID，用于重试去重）、`name`（1–120 字符）、`email`（有效格式、至多 254 字符）、`message`（可选、至多 2000 字符）、`preview_token`、可选 `quote_token`、`route_choices`。未知字段/不允许的分支/篡改或错配快照返回 422；不能由客户端直接传金额覆盖后端报价。

提交成功或相同请求重试返回 201：

```json
{"reference":"TC-示例咨询编号","status":"received"}
```

只返回编号和接收状态，不返回客户列表、内部成本或运营信息。相同请求编号配不同内容返回 409 `ENQUIRY_RETRY_CONFLICT`；快照过期返回 409 `PREVIEW_EXPIRED`；存储不可用或文件模式返回 503 `ENQUIRY_UNAVAILABLE`。

数据库保存客人当时的公开内容、联系信息、所展示报价和当前复核结果；成功估算关联带成本/规则版本的报价快照，待确认也可以咨询。重复/并发请求不会重复创建咨询和报价。网页修改需求后须更新预览才能提交，失败保留联系信息。

接口只创建咨询，不发送邮件、不确认预订。运营本地查看方式见 [数据库使用说明](database-guide.md)，网页登录与通知仍待后续阶段。
