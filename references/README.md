# 参考材料

这里的文件服务于业务参考、作品集或历史记录，不是现行网站运行代码。

- `business/`：业务工作指引与上海行程材料。
- `portfolio/site/`：原个人 React/Vite 作品集，独立的 package.json，与未来 `frontend/` 无关。
- `portfolio/case-study/`：原“作品集”文件夹，包含 PRD、原型和设计规范。
- `private/`：原“资料”、旧付款文件、客户信息表、路书和原始产品大文件。该目录保留在本地，被 Git 和 Docker 排除。

内容相似但用途不同的材料保留；只有字节内容完全相同的两组文件合并。不得把这里的私人数据直接移入前端公开资源。
